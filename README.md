# 百度网盘重复文件一键清理助手 (Chrome 扩展免 VIP 版)

专为谷歌浏览器 (Google Chrome) 设计的百度网盘重复文件批量删除插件。打破百度网盘网页版在「垃圾文件清理」功能中删除重复文件强行弹出 SVIP/VIP 付费弹窗的限制，实现免费、安全、自动化的批量循环删除。

---

## 🌟 核心功能与特色

- **免 VIP 限制删除**：绕过前端付费提示窗，直接使用百度网盘基础文件 API (`POST /api/filemanager?opera=delete`) 批量删除。
- **自动抓取勾选**：自动识别人在页面上点击「智能选择」或手动勾选的重复文件列表。
- **悬浮面板控制**：在百度网盘网页右下角注入直观的控制面板与进度条。
- **循环分批防封**：采用分批次 (每批20项) + 循环延时 (600ms) 机制，稳定不触发网盘频率控制。
- **回收站安全保障**：删除的文件正常进入网盘回收站，保留 10 天，误删可一键恢复。
- **双重模式**：提供网页悬浮窗自动清理 + 扩展弹窗手动粘贴路径删除双重保障。

## 📦 安装教程 (Chrome 浏览器)

1. **下载/解压源码**：
   确保插件目录所在路径（例如：`d:\CSharp\BaiduPanExtension`）。

2. **打开 Chrome 扩展管理**：
   在 Chrome 浏览器地址栏中输入并打开：
   ```text
   chrome://extensions/
   ```

3. **开启开发者模式**：
   在页面右上角，勾选并开启 **「开发者模式」 (Developer mode)** 开关。

4. **加载已解压的扩展程序**：
   - 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)** 按钮。
   - 选择文件夹：`d:\CSharp\BaiduPanExtension`。
   - 看到列表中出现 **「百度网盘重复文件一键清理助手 (免VIP)」** 即表示安装成功！

## 🚀 使用指南

1. **打开百度网盘并登录**：
   访问 [百度网盘网页版](https://pan.baidu.com/) 并登录账号。

2. **进入重复文件清理页面**：
   - 点击顶部菜单栏的 **「垃圾文件清理」**。
   - 点击左侧/顶部的 **「重复文件」** 标签（展示重复文件列表）。

3. **智能选择重复文件**：
   - 点击页面自带的 **「智能选择（推荐）」** 按钮，网盘会自动帮你勾选每个重复组中的副本文件。
   - 你也可以手动勾选想要清理的文件。

4. **一键删除**：
   - 查看页面右下角插件自动生成的悬浮面板（显示：`已检测选中: X 个文件`）。
   - 点击 **「🚀 免VIP一键删除」** 按钮。
   - 弹窗将显示实时进度条与删除日志，等待删除完成即可！

## ❓ 常见问题 (FAQ)

- **Q: 删除的文件真的彻底消失了吗？**
  A: 不是。删掉的文件会送入百度网盘的「回收站」，在回收站中可正常看到并一键还原。

- **Q: 为什么提示未能获取到 bdstoken？**
  A: 插件会自动从页面上下文 `yunData` 或 API 抓取 token。如果提示缺失，请刷新一下百度网盘网页，确保账号已正常登录即可。

- **Q: 一次可以删除多少个文件？**
  A: 理论上无上限。插件会自动将几百上千个文件拆分为每 20 项一组，循环分批删除，避免单次请求超时。
